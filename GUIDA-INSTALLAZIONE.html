Installare The Ultraspeaker Image Lab in PowerPoint

Ultimo aggiornamento: 12 novembre 2026

Titolare: Nicholas D. Charles (The Ultraspeaker) · info@theultraspeaker.com

Il pannello per PowerPoint è in fase di prova e sarà disponibile a breve. Nel frattempo usa la versione web, senza installare nulla: niki977.github.io/ultraspeaker-image-lab.

Tre passaggi, circa 10 minuti, da fare una volta sola per ogni computer. Poi il pulsante Image Lab resta nella scheda Home di PowerPoint, nel gruppo The Ultraspeaker.

Requisiti

PowerPoint di Microsoft 365 aggiornato: Windows 2601 o successivo, Mac 16.105 o successivo, oppure PowerPoint per il web. PowerPoint per iPad non è supportato.

1 · Il file da installare

Ti serve solo il manifest image-lab-manifest.xml, che trovi nel repository github.com/niki977/ultraspeaker-image-lab o che ti mandiamo su richiesta. Punta già a https://niki977.github.io/ultraspeaker-image-lab/: non devi modificarlo.

2 · PowerPoint per Mac

  1. Chiudi PowerPoint (⌘Q).
  2. Nel Finder premi ⌘ + Maiusc + G e incolla: ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/
  3. Se non c'è, crea una cartella chiamata wef e copia dentro image-lab-manifest.xml. Se c'è già una versione precedente, sostituiscila.
  4. Apri PowerPoint e una presentazione: in Home trovi il gruppo The Ultraspeaker con il pulsante Image Lab.

Se compare ancora la versione vecchia: chiudi PowerPoint, svuota ~/Library/Containers/com.microsoft.Powerpoint/Data/Library/Caches e riaprilo.

2 · PowerPoint per Windows

  1. Crea una cartella, per esempio C:\ImageLab, e copia dentro image-lab-manifest.xml.
  2. Tasto destro sulla cartella → Proprietà → Condivisione → Condividi…, scegli il tuo utente, Condividi e Fine. Annota il percorso di rete (simile a \\NOME-PC\ImageLab).
  3. In PowerPoint: File → Opzioni → Centro protezione → Impostazioni Centro protezione… → Cataloghi di componenti aggiuntivi attendibili. Incolla il percorso di rete in URL catalogo, Aggiungi catalogo, spunta Mostra nel menu, poi OK.
  4. Chiudi e riapri PowerPoint, vai su Home → Componenti aggiuntivi → CARTELLA CONDIVISA, seleziona The Ultraspeaker Image Lab e Aggiungi.

2 · PowerPoint per il web

Home → Componenti aggiuntivi → Altri componenti aggiuntivi → I miei componenti aggiuntivi → Carica il mio componente aggiuntivo e seleziona image-lab-manifest.xml.

3 · Prova

  1. Inserisci una foto in una slide e selezionala.
  2. Fai clic su Home → Image Lab: il pannello mostra la foto e l'istogramma.
  3. Scegli lo stile Palco e fai clic su Applica alla slide.

Sul PC aziendale l'IT può distribuire l'add-in dal Microsoft 365 admin center con il solo file del manifest.

Installing The Ultraspeaker Image Lab in PowerPoint

Last updated: 12 November 2026

Owner: Nicholas D. Charles (The Ultraspeaker) · info@theultraspeaker.com

The PowerPoint pane is being tested and will be available soon. In the meantime use the web version, with nothing to install: niki977.github.io/ultraspeaker-image-lab.

Three steps, about 10 minutes, to do once per computer. After that the Image Lab button stays in PowerPoint's Home tab, in the The Ultraspeaker group.

Requirements

An up-to-date Microsoft 365 PowerPoint: Windows 2601 or later, Mac 16.105 or later, or PowerPoint for the web. PowerPoint for iPad is not supported.

1 · The file to install

You only need the manifest image-lab-manifest.xml, available in the repository github.com/niki977/ultraspeaker-image-lab or from us on request. It already points to https://niki977.github.io/ultraspeaker-image-lab/: you do not need to edit it.

2 · PowerPoint for Mac

  1. Quit PowerPoint (⌘Q).
  2. In the Finder press ⌘ + Shift + G and paste: ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/
  3. If it is not there, create a folder called wef and copy image-lab-manifest.xml into it. If an earlier version is already there, replace it.
  4. Open PowerPoint and a presentation: in Home you will find the The Ultraspeaker group with the Image Lab button.

If the old version still appears: quit PowerPoint, empty ~/Library/Containers/com.microsoft.Powerpoint/Data/Library/Caches and open it again.

2 · PowerPoint for Windows

  1. Create a folder, for example C:\ImageLab, and copy image-lab-manifest.xml into it.
  2. Right-click the folder → Properties → Sharing → Share…, choose your user, Share and Done. Note the network path (similar to \\PC-NAME\ImageLab).
  3. In PowerPoint: File → Options → Trust Center → Trust Center Settings… → Trusted Add-in Catalogs. Paste the network path in Catalog Url, Add catalog, tick Show in Menu, then OK.
  4. Close and reopen PowerPoint, go to Home → Add-ins → SHARED FOLDER, select The Ultraspeaker Image Lab and Add.

2 · PowerPoint for the web

Home → Add-ins → More Add-ins → My Add-ins → Upload My Add-in and select image-lab-manifest.xml.

3 · Try it

  1. Insert a photo on a slide and select it.
  2. Click Home → Image Lab: the pane shows the photo and the histogram.
  3. Choose the Stage style and click Apply to slide.

On a company PC, IT can deploy the add-in from the Microsoft 365 admin center with just the manifest file.

The Ultraspeaker Image Lab in PowerPoint installieren

Zuletzt aktualisiert: 12. November 2026

Verantwortlich: Nicholas D. Charles (The Ultraspeaker) · info@theultraspeaker.com

Der Bereich für PowerPoint wird gerade getestet und ist bald verfügbar. Nutzen Sie bis dahin die Webversion, ohne etwas zu installieren: niki977.github.io/ultraspeaker-image-lab.

Drei Schritte, etwa 10 Minuten, einmal pro Computer. Danach bleibt die Schaltfläche Image Lab auf der Registerkarte Start von PowerPoint, in der Gruppe The Ultraspeaker.

Voraussetzungen

Ein aktuelles PowerPoint aus Microsoft 365: Windows 2601 oder neuer, Mac 16.105 oder neuer oder PowerPoint für das Web. PowerPoint für iPad wird nicht unterstützt.

1 · Die zu installierende Datei

Sie brauchen nur das Manifest image-lab-manifest.xml, das im Repository github.com/niki977/ultraspeaker-image-lab liegt oder das wir Ihnen auf Anfrage schicken. Es verweist bereits auf https://niki977.github.io/ultraspeaker-image-lab/: Sie müssen es nicht ändern.

2 · PowerPoint für Mac

  1. Beenden Sie PowerPoint (⌘Q).
  2. Drücken Sie im Finder ⌘ + Umschalt + G und fügen Sie ein: ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/
  3. Falls er fehlt, legen Sie einen Ordner namens wef an und kopieren Sie image-lab-manifest.xml hinein. Liegt dort schon eine ältere Version, ersetzen Sie sie.
  4. Öffnen Sie PowerPoint und eine Präsentation: Unter Start finden Sie die Gruppe The Ultraspeaker mit der Schaltfläche Image Lab.

Erscheint noch die alte Version: Beenden Sie PowerPoint, leeren Sie ~/Library/Containers/com.microsoft.Powerpoint/Data/Library/Caches und öffnen Sie es erneut.

2 · PowerPoint für Windows

  1. Legen Sie einen Ordner an, zum Beispiel C:\ImageLab, und kopieren Sie image-lab-manifest.xml hinein.
  2. Rechtsklick auf den Ordner → Eigenschaften → Freigabe → Freigeben…, wählen Sie Ihren Benutzer, Freigeben und Fertig. Notieren Sie den Netzwerkpfad (ähnlich \\PC-NAME\ImageLab).
  3. In PowerPoint: Datei → Optionen → Trust Center → Einstellungen für das Trust Center… → Kataloge vertrauenswürdiger Add-Ins. Fügen Sie den Netzwerkpfad unter Katalog-URL ein, Katalog hinzufügen, aktivieren Sie Im Menü anzeigen, dann OK.
  4. Schließen Sie PowerPoint, öffnen Sie es erneut, gehen Sie zu Start → Add-Ins → FREIGEGEBENER ORDNER, wählen Sie The Ultraspeaker Image Lab und Hinzufügen.

2 · PowerPoint für das Web

Start → Add-Ins → Weitere Add-Ins → Meine Add-Ins → Mein Add-In hochladen und wählen Sie image-lab-manifest.xml.

3 · Ausprobieren

  1. Fügen Sie ein Foto auf einer Folie ein und wählen Sie es aus.
  2. Klicken Sie auf Start → Image Lab: Der Bereich zeigt das Foto und das Histogramm.
  3. Wählen Sie den Stil Bühne und klicken Sie auf Auf Folie anwenden.

Auf einem Firmen-PC kann die IT das Add-in über das Microsoft 365 Admin Center mit nur der Manifestdatei verteilen.
