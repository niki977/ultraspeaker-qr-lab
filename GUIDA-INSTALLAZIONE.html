Installare The Ultraspeaker QR Lab in PowerPoint

Tre passaggi, circa 10 minuti, da fare una volta sola per ogni computer (Mac o Windows). Poi il pulsante QR Code resta nella scheda Inserisci di PowerPoint, con le due sezioni QR e Reference.

1Metti online i file (GitHub Pages, gratuito)

Gli add-in di Office si caricano sempre da un indirizzo web sicuro (https). GitHub Pages lo fornisce gratis.

  1. Crea un account gratuito su github.com (se non ce l'hai).
  2. + → New repository. Nome: ultraspeaker-qr-lab, visibilità Public, poi Create repository.
  3. Carica nel repository: index.html, taskpane.html, app.js, reference.js, i18n.js, qrcode.js, support.html, privacy.html, terms.html, GUIDA-INSTALLAZIONE.html, manifest.xml e le cartelle assets e fonts. Con GitHub Desktop: copia i file nella cartella del repository, poi Commit to main e Push origin.
  4. Settings → Pages: in “Branch” scegli main e / (root), poi Save.
  5. Dopo 1–2 minuti apri https://niki977.github.io/ultraspeaker-qr-lab/taskpane.html: se vedi The Ultraspeaker QR Lab, è online.

2Il manifest è già pronto

manifest.xml è già compilato per l'account GitHub niki977 e punta a https://niki977.github.io/ultraspeaker-qr-lab/. Non devi modificarlo: basta che il repository si chiami esattamente ultraspeaker-qr-lab.

3Installa in PowerPoint per Mac

  1. Chiudi PowerPoint.
  2. Nel Finder premi ⌘ + Maiusc + G e incolla: ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/
  3. Se non c'è, crea una cartella chiamata wef e copia dentro manifest.xml.
  4. Apri PowerPoint e una presentazione, vai su Home → Componenti aggiuntivi e scegli The Ultraspeaker QR Lab.
  5. Da quel momento trovi il pulsante QR Code nella scheda Inserisci.

Se il comando non compare: chiudi PowerPoint del tutto (⌘Q) e riaprilo.

3Installa in PowerPoint per Windows

  1. Crea una cartella, per esempio C:\QRLab, e copia dentro manifest.xml.
  2. Tasto destro sulla cartella → Proprietà → Condivisione → Condividi…, scegli il tuo utente, Condividi e Fine. Annota il percorso di rete (simile a \\NOME-PC\QRLab).
  3. In PowerPoint: File → Opzioni → Centro protezione → Impostazioni Centro protezione… → Cataloghi di componenti aggiuntivi attendibili. Incolla il percorso di rete in URL catalogo, Aggiungi catalogo, spunta Mostra nel menu, poi OK.
  4. Chiudi e riapri PowerPoint, vai su Home → Componenti aggiuntivi → CARTELLA CONDIVISA, seleziona The Ultraspeaker QR Lab e Aggiungi.

Sul PC aziendale l'IT può distribuire l'add-in dal Microsoft 365 admin center con il solo file manifest.xml.

+Altri modi

  • PowerPoint sul web: Home → Componenti aggiuntivi → Altri componenti aggiuntivi → I miei componenti aggiuntivi → Carica il mio componente aggiuntivo e seleziona manifest.xml.
  • Versione web (senza installare nulla): https://niki977.github.io/ultraspeaker-qr-lab/. Crea i QR e le citazioni anche da telefono.

RLa sezione Reference in breve

  1. Nel pannello scegli Reference, scrivi un DOI, un PMID, un link o il titolo e fai clic su Cerca.
  2. Controlla l'anteprima e gli eventuali avvisi (ritrattato, corretto, duplicato).
  3. Scegli stile (Vancouver, APA 7, AMA, Harvard), formato della citazione e layout, poi Inserisci nella slide.
  4. Alla fine usa Aggiorna numerazione e citazioni e Genera le slide «Bibliografia».

La ricerca richiede internet. Il posizionamento automatico e la bibliografia richiedono PowerPoint per Microsoft 365 aggiornato. Dettagli nella pagina Supporto.

?Buono a sapersi

  • Per aggiornare l'add-in basta ricaricare i file nuovi su GitHub: PowerPoint userà la nuova versione alla prossima apertura. Se cambia manifest.xml, ricopialo anche nella cartella wef (Mac) o nella cartella condivisa (Windows).
  • I QR sono statici: funzionano per sempre e senza abbonamenti. Prova sempre la scansione prima di stampare.
  • L'add-in è in italiano, inglese, spagnolo, francese e tedesco; la lingua si cambia dal menu in alto a destra del pannello.

Installing The Ultraspeaker QR Lab in PowerPoint

Three steps, about 10 minutes, to do once per computer (Mac or Windows). After that, the QR Code button stays in PowerPoint's Insert tab, with its two sections QR and Reference.

1Put the files online (GitHub Pages, free)

Office add-ins always load from a secure web address (https). GitHub Pages provides one for free.

  1. Create a free account on github.com (if you don't have one).
  2. + → New repository. Name: ultraspeaker-qr-lab, visibility Public, then Create repository.
  3. Upload to the repository: index.html, taskpane.html, app.js, reference.js, i18n.js, qrcode.js, support.html, privacy.html, terms.html, GUIDA-INSTALLAZIONE.html, manifest.xml and the assets and fonts folders. With GitHub Desktop: copy the files into the repository folder, then Commit to main and Push origin.
  4. Settings → Pages: under “Branch” choose main and / (root), then Save.
  5. After 1–2 minutes open https://niki977.github.io/ultraspeaker-qr-lab/taskpane.html: if you see The Ultraspeaker QR Lab, it's online.

2The manifest is ready

manifest.xml is already set up for the GitHub account niki977 and points to https://niki977.github.io/ultraspeaker-qr-lab/. You don't need to edit it, as long as the repository is named exactly ultraspeaker-qr-lab.

3Install in PowerPoint for Mac

  1. Quit PowerPoint.
  2. In Finder press ⌘ + Shift + G and paste: ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/
  3. If it doesn't exist, create a folder named wef and copy manifest.xml into it.
  4. Open PowerPoint and a presentation, go to Home → Add-ins and choose The Ultraspeaker QR Lab.
  5. From then on you'll find the QR Code button in the Insert tab.

If the command doesn't appear, quit PowerPoint completely (⌘Q) and reopen it.

3Install in PowerPoint for Windows

  1. Create a folder, for example C:\QRLab, and copy manifest.xml into it.
  2. Right-click the folder → Properties → Sharing → Share…, choose your user, Share and Done. Note the network path (similar to \\PC-NAME\QRLab).
  3. In PowerPoint: File → Options → Trust Center → Trust Center Settings… → Trusted Add-in Catalogs. Paste the network path into Catalog Url, Add catalog, tick Show in Menu, then OK.
  4. Close and reopen PowerPoint, go to Home → Add-ins → SHARED FOLDER, select The Ultraspeaker QR Lab and Add.

On a company PC, IT can deploy the add-in from the Microsoft 365 admin center using just manifest.xml.

+Other ways

  • PowerPoint on the web: Home → Add-ins → More Add-ins → My Add-ins → Upload My Add-in and select manifest.xml.
  • Web version (nothing to install): https://niki977.github.io/ultraspeaker-qr-lab/. It creates QR codes and citations, from a phone too.

RThe Reference section at a glance

  1. In the panel choose Reference, type a DOI, a PMID, a link or the title and click Search.
  2. Check the preview and any warnings (retracted, corrected, duplicate).
  3. Choose the style (Vancouver, APA 7, AMA, Harvard), citation format and layout, then Insert into slide.
  4. At the end, use Update numbering and citations and Create the “References” slides.

Searching needs an internet connection. Automatic positioning and the bibliography need an up-to-date PowerPoint for Microsoft 365. Details on the Support page.

?Good to know

  • To update the add-in, just upload the new files to GitHub: PowerPoint uses the new version the next time it opens. If manifest.xml changes, copy it again into the wef folder (Mac) or the shared folder (Windows).
  • QR codes are static: they work forever, without subscriptions. Always test the scan before printing.
  • The add-in is available in Italian, English, Spanish, French and German; change the language from the menu at the top right of the panel.

The Ultraspeaker QR Lab in PowerPoint installieren

Drei Schritte, etwa 10 Minuten, einmal pro Computer (Mac oder Windows). Danach bleibt die Schaltfläche QR Code in der Registerkarte Einfügen von PowerPoint, mit den beiden Bereichen QR und Literatur.

1Dateien online stellen (GitHub Pages, kostenlos)

Office-Add-ins werden immer von einer sicheren Webadresse (https) geladen. GitHub Pages stellt sie kostenlos bereit.

  1. Erstellen Sie ein kostenloses Konto auf github.com (falls noch nicht vorhanden).
  2. + → New repository. Name: ultraspeaker-qr-lab, Sichtbarkeit Public, dann Create repository.
  3. Laden Sie in das Repository hoch: index.html, taskpane.html, app.js, reference.js, i18n.js, qrcode.js, support.html, privacy.html, terms.html, GUIDA-INSTALLAZIONE.html, manifest.xml sowie die Ordner assets und fonts. Mit GitHub Desktop: Dateien in den Repository-Ordner kopieren, dann Commit to main und Push origin.
  4. Settings → Pages: unter „Branch“ main und / (root) wählen, dann Save.
  5. Öffnen Sie nach 1–2 Minuten https://niki977.github.io/ultraspeaker-qr-lab/taskpane.html: Wenn Sie The Ultraspeaker QR Lab sehen, ist es online.

2Das Manifest ist fertig

manifest.xml ist bereits für das GitHub-Konto niki977 eingerichtet und verweist auf https://niki977.github.io/ultraspeaker-qr-lab/. Sie müssen es nicht ändern, solange das Repository genau ultraspeaker-qr-lab heißt.

3In PowerPoint für Mac installieren

  1. Beenden Sie PowerPoint.
  2. Drücken Sie im Finder ⌘ + Umschalt + G und fügen Sie ein: ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/
  3. Falls nicht vorhanden, erstellen Sie einen Ordner namens wef und kopieren Sie manifest.xml hinein.
  4. Öffnen Sie PowerPoint und eine Präsentation, gehen Sie zu Start → Add-Ins und wählen Sie The Ultraspeaker QR Lab.
  5. Danach finden Sie die Schaltfläche QR Code in der Registerkarte Einfügen.

Wenn der Befehl nicht erscheint, beenden Sie PowerPoint vollständig (⌘Q) und öffnen Sie es erneut.

3In PowerPoint für Windows installieren

  1. Erstellen Sie einen Ordner, zum Beispiel C:\QRLab, und kopieren Sie manifest.xml hinein.
  2. Rechtsklick auf den Ordner → Eigenschaften → Freigabe → Freigabe…, Ihren Benutzer wählen, Freigabe und Fertig. Notieren Sie den Netzwerkpfad (ähnlich \\PC-NAME\QRLab).
  3. In PowerPoint: Datei → Optionen → Trust Center → Einstellungen für das Trust Center… → Kataloge vertrauenswürdiger Add-Ins. Netzwerkpfad bei Katalog-URL einfügen, Katalog hinzufügen, Im Menü anzeigen aktivieren, dann OK.
  4. PowerPoint schließen und neu öffnen, Start → Add-Ins → FREIGEGEBENER ORDNER, The Ultraspeaker QR Lab auswählen und Hinzufügen.

Auf einem Firmen-PC kann die IT das Add-in über das Microsoft 365 Admin Center allein mit der Datei manifest.xml verteilen.

+Weitere Möglichkeiten

  • PowerPoint im Web: Start → Add-Ins → Weitere Add-Ins → Meine Add-Ins → Mein Add-In hochladen und manifest.xml auswählen.
  • Webversion (ohne Installation): https://niki977.github.io/ultraspeaker-qr-lab/. Sie erstellt QR-Codes und Zitate, auch auf dem Telefon.

RDer Bereich Literatur in Kürze

  1. Wählen Sie im Bereich Literatur, geben Sie eine DOI, PMID, einen Link oder den Titel ein und klicken Sie auf Suchen.
  2. Prüfen Sie die Vorschau und eventuelle Warnungen (zurückgezogen, korrigiert, Duplikat).
  3. Wählen Sie Stil (Vancouver, APA 7, AMA, Harvard), Zitatformat und Layout, dann In Folie einfügen.
  4. Verwenden Sie am Ende Nummerierung und Zitate aktualisieren und Folien „Literatur“ erstellen.

Die Suche erfordert eine Internetverbindung. Automatische Platzierung und Literaturverzeichnis erfordern ein aktuelles PowerPoint für Microsoft 365. Details auf der Seite Support.

?Gut zu wissen

  • Zum Aktualisieren genügt es, die neuen Dateien auf GitHub hochzuladen: PowerPoint verwendet die neue Version beim nächsten Öffnen. Ändert sich manifest.xml, kopieren Sie es erneut in den Ordner wef (Mac) bzw. den freigegebenen Ordner (Windows).
  • QR-Codes sind statisch: Sie funktionieren für immer und ohne Abonnement. Testen Sie den Scan immer vor dem Drucken.
  • Das Add-in ist auf Italienisch, Englisch, Spanisch, Französisch und Deutsch verfügbar; die Sprache ändern Sie über das Menü oben rechts im Bereich.
